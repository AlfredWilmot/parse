# Parse
An experimental CLI tool for parsing between various common data-formats.

> [!WARNING]
> 🚧 WORK IN PROGRESS 🚧
> >
> Currently only implements parsing a stream of [Bencoding](https://wiki.theory.org/BitTorrentSpecification#Bencoding) data directly into [JSON](https://ecma-international.org/wp-content/uploads/ECMA-404_2nd_edition_december_2017.pdf), along with some unit-tests and basic CI.
